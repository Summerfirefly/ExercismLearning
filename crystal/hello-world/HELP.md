# Help

## 运行测试

用以下命令运行测试：

```bash
$ crystal spec
```

## 跳过的测试

每个测试套件中，除第一个测试外，其余测试都已被跳过。

一旦某个测试通过，你就可以把`pending`改成`it`，让下一个测试不再被跳过。

## 提交你的解答

你可以使用`exercism submit src/hello_world.cr`命令提交你的解答。
这个命令会把你的解答上传到 Exercism 网站，并打印出解答页面的 URL。

你也可以提交一个不完整的解答，这样可以：

- 看看别人是如何完成这道练习的
- 向导师寻求帮助

## 需要帮助吗？

如果你在解这道练习时需要帮助，请查看以下页面：

- [Crystal 轨道文档](https://exercism.org/docs/tracks/crystal)
- [Crystal 轨道在论坛上的编程版块](https://forum.exercism.org/c/programming/crystal)
- [Exercism 在论坛上的编程版块](https://forum.exercism.org/c/programming/5)
- [常见问题解答](https://exercism.org/docs/using/faqs)

如果这些资源还不够，你也可以提交（不完整的）解答，以申请导师指导。

如果你遇到问题需要帮助，可以使用以下资源之一：

- [Crystal API](http://crystal-lang.org/api/)
- [r/crystal_programming/](https://www.reddit.com/r/crystal_programming/) 是 Crystal 的 Reddit 子版块。
- [StackOverflow](https://stackoverflow.com/questions/tagged/crystal-lang) 可以用来搜索你的问题，看看是否已经有人解答过。你也可以在上面提问和回答问题。
- [Crystal Forum](https://forum.crystal-lang.org/) 是 Crystal 的官方论坛。
