# Help

## 运行测试

你可以在练习目录中打开命令行，然后运行 [`dotnet test` 命令](https://docs.microsoft.com/en-us/dotnet/core/tools/dotnet-test)来运行测试。
另外，大多数 IDE 都内置了运行测试的功能，包括 [Visual Studio](https://docs.microsoft.com/en-us/visualstudio/test/run-unit-tests-with-test-explorer)、[Rider](https://www.jetbrains.com/help/rider/Unit_Testing_in_Solution.html) 和 [Visual Studio Code](https://github.com/OmniSharp/omnisharp-vscode/wiki/How-to-run-and-debug-unit-tests)。
更多信息请查看[测试页面](https://exercism.org/docs/tracks/csharp/tests)。

## 跳过的测试

一开始只会启用第一个测试。
这是为了鼓励你一步一步地解决练习。
当第一个测试通过后，从下一个测试中移除 `Skip` 属性，然后努力让那个测试通过。

## 提交你的解答

你可以使用`exercism submit HelloWorld.cs`命令提交你的解答。
这个命令会把你的解答上传到 Exercism 网站，并打印出解答页面的 URL。

你也可以提交一个不完整的解答，这样可以：

- 看看别人是如何完成这道练习的
- 向导师寻求帮助

## 需要帮助吗？

如果你在解这道练习时需要帮助，请查看以下页面：

- [C# 轨道文档](https://exercism.org/docs/tracks/csharp)
- [C# 轨道在论坛上的编程版块](https://forum.exercism.org/c/programming/csharp)
- [Exercism 在论坛上的编程版块](https://forum.exercism.org/c/programming/5)
- [常见问题解答](https://exercism.org/docs/using/faqs)

如果这些资源还不够，你也可以提交（不完整的）解答，以申请导师指导。

遇到问题时，可以通过以下资源获取帮助：

- [/r/csharp](https://www.reddit.com/r/csharp) 是 C# 的 subreddit。
- [StackOverflow](http://stackoverflow.com/questions/tagged/c%23) 可以用来搜索你的问题，看看是否已经有人回答过。你也可以在上面提问和回答别人的问题。
