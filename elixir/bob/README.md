## Introduction

鲍勃是个[无精打采][lackadaisical]的少年。
他喜欢觉得自己很酷。
而且他绝对不会为什么事情兴奋起来。
那样就不酷了。

人们跟他说话时，他的回答相当有限。

[lackadaisical]: https://www.collinsdictionary.com/dictionary/english/lackadaisical

## Instructions

你的任务是判断当有人对 Bob 说话，或者问他问题时，Bob 会回答什么。

Bob 只会给出五种回答之一：

- **"Sure."**
  如果你问他一个问题，比如 "How are you?"，他就会这样回答。
  问题遵循的约定是：以问号结尾。
- **"Whoa, chill out!"**
  如果你冲他大喊，他就会这样回答。
  大喊遵循的约定是：全部使用大写字母。
- **"Calm down, I know what I'm doing!"**
  如果你冲他大喊着提出问题，他就会这样说。
- **"Fine. Be that way!"**
  这是他对沉默的回应。
  沉默的约定是什么都不说，或者使用各种空白字符的组合。
- **"Whatever."**
  这是他对其余任何情况的回答。
