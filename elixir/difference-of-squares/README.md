# 平方差

欢迎来到 Exercism Elixir 轨道中的 平方差。

## Instructions

求前 N 个自然数之和的平方与它们平方之和的差。

前十个自然数之和的平方是
(1 + 2 + ... + 10)² = 55² = 3025。

前十个自然数平方之和是
1² + 2² + ... + 10² = 385。

因此，前十个自然数之和的平方与前十个自然数平方之和的差是 3025 - 385 = 2640。

你不需要自己从基本原理出发推导出一个高效的解法；查阅资料是允许的，甚至是值得鼓励的。
为问题找到最佳的算法，是软件工程中的一项关键技能。
