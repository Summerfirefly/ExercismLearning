## Introduction

在某些英语口音里，如果把“two for”说得快一些，听起来就像“two fer”。Two-for-one 是一种说法，意思是买一个还能免费再得一个。所以“two-fer”这个说法往往暗示着买一送一的优惠。

想象有一家面包店，在节日期间推出了这样的优惠：花一份钱就能买到两块饼干（“two-fer one!”）。你接受了这个优惠，并且（非常大方地）决定把多出来的那块饼干送给排队中的另一个人。

## Instructions

你的任务是决定：在把多出来的那块饼干送出去时，你要说些什么。

如果你知道对方的名字（例如，对方叫 Do-yun），那么你要说：

```text
One for Do-yun, one for me.
```

如果你不知道对方的名字，那就改说 _you_。

```text
One for you, one for me.
```

下面是一些例子：

| 名字   | 对话                        |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
