# Help

## 运行测试

要运行提供的测试，你需要 Minitest gem。打开终端窗口，运行以下命令安装 minitest：

```
gem install minitest
```


在练习目录中运行以下命令来运行测试：

```
ruby <snake-case-exercise>_test.rb
```

请把`<snake-case-exercise>`替换为你的练习名称（snake_case 格式）。

## 彩色输出

你可以`require 'minitest/pride'`，或者运行以下命令来获得彩色输出：

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```

## 提交你的解答

你可以使用`exercism submit assembly_line.rb`命令提交你的解答。
这个命令会把你的解答上传到 Exercism 网站，并打印出解答页面的 URL。

你也可以提交一个不完整的解答，这样可以：

- 看看别人是如何完成这道练习的
- 向导师寻求帮助

## 需要帮助吗？

如果你在解这道练习时需要帮助，请查看以下页面：

- [Ruby 轨道文档](https://exercism.org/docs/tracks/ruby)
- [Ruby 轨道在论坛上的编程版块](https://forum.exercism.org/c/programming/ruby)
- [Exercism 在论坛上的编程版块](https://forum.exercism.org/c/programming/5)
- [常见问题解答](https://exercism.org/docs/using/faqs)

如果这些资源还不够，你也可以提交（不完整的）解答，以申请导师指导。

如果遇到问题需要帮助，可以使用以下资源之一：

- [Ruby 文档](http://ruby-doc.org/)
- [StackOverflow](http://stackoverflow.com/questions/tagged/ruby)
- [/r/ruby](https://www.reddit.com/r/ruby) 是 Ruby 的子版块。
