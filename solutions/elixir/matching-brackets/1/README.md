# 匹配括号

欢迎来到 Exercism Elixir 轨道中的 匹配括号。
如果你在运行测试或提交代码时需要帮助，请查看`HELP.md`。

## Introduction

你有机会为 Bracketeer™ 编写软件，这是一台古老却功能强大的大型机。
它上面运行的软件是用一种专有语言编写的。
这种语言的语法大部分看起来很熟悉，但你会注意到_大量_的方括号、大括号和圆括号。
尽管 Bracketeer™ 功能强大，却缺乏灵活性。
只要源代码里出现任何不配对的方括号、大括号或圆括号，Bracketeer™ 就会崩溃，必须重启。
为了避免这种情况，你开始编写一段代码，用来在把程序放到 Bracketeer™ 上运行之前，先检查方括号、大括号和圆括号是否配对。

## Instructions

给定一个字符串，其中可能包含方括号`[]`、大括号`{}`、圆括号`()`或它们的任意组合，请验证所有括号对是否都匹配且嵌套正确。其他字符一律忽略。例如，`"{what is (42)}?"` 是平衡的，而`"[text}"`则不是。
