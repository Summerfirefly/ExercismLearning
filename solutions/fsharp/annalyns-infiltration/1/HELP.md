# Help

## 运行测试

在练习目录下打开命令提示符，然后运行 [`dotnet test` 命令](https://docs.microsoft.com/en-us/dotnet/core/tools/dotnet-test)，就可以运行测试。
或者，大多数 IDE 都内置了运行测试的功能，包括 [Visual Studio](https://docs.microsoft.com/en-us/visualstudio/test/run-unit-tests-with-test-explorer)、[Rider](https://www.jetbrains.com/help/rider/Unit_Testing_in_Solution.html) 和 [Visual Studio code](https://github.com/OmniSharp/omnisharp-vscode/wiki/How-to-run-and-debug-unit-tests)。
更多信息请见[测试页面](https://exercism.io/tracks/fsharp/tests)。

## 跳过的测试

一开始只会启用第一个测试。
这样做是为了鼓励你一步一步地解决练习。
第一个测试通过之后，把 `Skip` 属性从下一个测试中删掉，然后想办法让那个测试也通过。

## 提交你的解答

你可以使用`exercism submit AnnalynsInfiltration.fs`命令提交你的解答。
这个命令会把你的解答上传到 Exercism 网站，并打印出解答页面的 URL。

你也可以提交一个不完整的解答，这样可以：

- 看看别人是如何完成这道练习的
- 向导师寻求帮助

## 需要帮助吗？

如果你在解这道练习时需要帮助，请查看以下页面：

- [F# 轨道文档](https://exercism.org/docs/tracks/fsharp)
- [F# 轨道在论坛上的编程版块](https://forum.exercism.org/c/programming/fsharp)
- [Exercism 在论坛上的编程版块](https://forum.exercism.org/c/programming/5)
- [常见问题解答](https://exercism.org/docs/using/faqs)

如果这些资源还不够，你也可以提交（不完整的）解答，以申请导师指导。

如果你遇到了困难，可以通过以下资源寻求帮助：

- [/r/fsharp](https://www.reddit.com/r/fsharp) 是 F# 的 subreddit。
- [StackOverflow](http://stackoverflow.com/questions/tagged/f%23) 可以用它搜索你的问题，看看是否已经有人解答过。你也可以在这里提问和回答问题。
